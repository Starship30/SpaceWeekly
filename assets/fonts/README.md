# Bundled video font

NotoSansCJKsc-Bold.otf is an unmodified Noto Sans CJK SC Bold font from the official Noto CJK repository. It is the final fallback for video text and numbers when Windows fonts are unavailable or unreadable. Keep OFL.txt with the font when redistributing.

- Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Bold.otf
- License: SIL Open Font License 1.1; full copyright and terms in OFL.txt.
- Size: 17,002,248 bytes.
- SHA-256: b5f0d1a190a7f9b43c310a8850630af12553df32c4c050543f9059732d9b4c0a

The font is bundled as-is, without subsetting or renaming. No font installation or runtime download is required. System fonts remain preferred when they can actually be loaded. The source URL is an upstream branch URL; use the SHA-256 above to identify these exact bytes.
