# SpaceWeekly 3.1.1 新闻生成范围误报修复

## 原因与修复

采集使用 `past_week` 等滚动发射范围时，`prepared_scope()` 每次按当前时间重新计算秒级边界。
新闻生成和导出把整份范围记录直接比较，即使用户没有修改日期，经过几秒也会拒绝已有资料。
此外，旧记录只保存 `net__gte` 和 `net__lt`，而滚动查询实际返回 `net__lte`，结束边界被漏存。

现在生成和导出共用范围比较：滚动范围比较所选模式和显示时区内的日期，
自定义范围继续比较完整边界。新闻日期、模式、时区真正变化仍会被拦截。
新采集保留完整结束边界并只记录一次范围；已有资料生成稿件时保留原始范围，不重新标成当前时刻。
旧格式缺失的结束边界不会补造；同一天同一范围可直接复用，跨日后的滚动范围仍需检查。
