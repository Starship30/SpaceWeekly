# 口播润色验收（2026-10-31）

新增可选的 **润色选中段口播**，复用现有文本 API，不联网补资料，不修改事实原稿、屏幕文字或视频样式。
段落保留任务 ID 和引文关联，改写后另行复核事实、数量、结果、用途、不确定性及新增结论。
程序检查数量/数字、来源和性质限定、句长及重复归因；段落长度不强制按固定比例缩减，避免为压缩删掉必要事实。
所有检查通过才原子应用；失败、取消或期间人工编辑均不覆盖原稿。机器复核不能替代人工判断。

## 界面与保存

- 任务表分别显示资料准备、来源、独立来源支持和人工确认。缓存命中和模型复核不产生人工/官方确认。
- 编辑器分开保存事实原稿、屏幕文字与最终朗读，预览发音替换后的实际 TTS 输入。
- Ctrl/Shift 选择重点或补充段落后润色；总览继续使用程序统计，过渡沿用原句。
- 选中人工编辑段落先提示；未选择的段落不变。自动保存恢复点，草稿及 `polish_history.json` 保留前后版本。
- 原稿、任务或出处关联变化使润色过期；手工朗读编辑不会继承模型的事实复核结论。
- `reading.txt` 和 `reading_map.json` 保存最终 TTS 输入及其屏幕对应关系；本轮未执行逐字对齐。
