# 每周发射综述音画同步

沿用四页桌面 UI、方案 B 圆角卡片、带间距上滑和左侧选框。本轮没有重新设计画面。

## 操作

优先在“配音与画面 → 配置语音”使用[自动配置](VOICE_SETUP.md)，由程序下载独立环境和强制对齐模型并完成真实联检。
原有环境可在“使用已有环境”填写解释器、模型、设备和语言后检查。手动维护环境时可使用：

```powershell
py -3.12 -m venv D:\Tools\spaceweekly-aligner
D:\Tools\spaceweekly-aligner\Scripts\python.exe -m pip install -r D:\Desktop\SpaceWeekly\tools\requirements-alignment.txt
```

模型使用 `Qwen/Qwen3-ForcedAligner-0.6B` 的本地完整目录。
接口依据 [Qwen 官方 ForcedAligner 用法](https://github.com/QwenLM/Qwen3-ASR#forcedaligner-usage)
和[官方封装源码](https://github.com/QwenLM/Qwen3-ASR/blob/main/qwen_asr/inference/qwen3_forced_aligner.py)：
直接调用 `Qwen3ForcedAligner.from_pretrained()` 与 `align(audio=..., text=..., language=...)`，读取结果的
`text`、`start_time`、`end_time`，不先做 ASR，也不让写稿模型计算切换秒数。

新生成稿从明确的任务 ID / 事实标记建立讲解单元；AI 生成接口支持逐句 `units`。
每单元有稳定 ID、段落 ID、原文位置、屏幕文字、任务范围及展示类型。
旧稿或改过的朗读稿不会凭名称猜关联。在配音页点“同步与画面 → 同步校准”，可重建单元并逐项检查任务、
选择分组 / 单任务 / 总结 / 过渡；需要时把光标放在原文里拆分单元。
这项关联确认不改变任务资料的人工核对状态。

配音仍按自然段生成，实际 TTS 输入和发音替换后的单元位置一同保存。
有对齐配置时，配音完成后卸载 TTS，再批量对齐；也可单独对齐本段或整稿。
对齐进程只在该批次驻留，取消时终止并确认退出，成功段落和音频保留。
缓存按音频 SHA256、最终朗读文本、模型文件信息、运行环境依赖元数据、工作脚本及设置区分。
只更新发生变化的段落；后续整期位置重新累计，其他音频不重生成。

“同步校准”表中可以编辑起止秒数、试听附近五秒、保存人工时间或恢复自动结果。
时间必须完整、有序、无重叠且不超出当前音频。音频、朗读文字或单元边界变化后，旧人工时间保留并标记待复查，
不套到新音频；若已有新自动结果则使用新结果，同时保留复查提示。

## 一份时间表

### 镜头编排

“配音与画面 → 同步与画面 → 镜头编排（高级）”提供独立分组过场总开关、逐组移除、撤销及恢复默认。
过场默认关闭，分组名称继续显示在方案 B 左侧标签中。首次分组介绍由开头概览承接；
旁白进入下一分组时，选框下滑并原位更新该组摘要，不停留在上一组总结，也不提前打开单项详情。
过渡和停顿保持此前完整画面；结尾保持最后摘要直到音频结束。
单任务转相邻多任务总结时，左侧选框原位拉伸覆盖连续任务；跨分组或不相邻任务分别高亮，不使用分页离场动画。

讲解单元与字幕仍保持原来的时间和关联，不逐句重建镜头。同一任务连续讲解按视觉内容合并，
不同单元 ID 不会让卡片重新进场；多任务总结在原位置更新。只有必要的任务变化使用定稿的卡片滑动。
不足三秒的独立状态会标为需要检查；极短状态仅做轻量更新，不延长声音或增加静音。

画面设置保存在草稿 `visuals` 中，包含 `group_cards` 和按段落/单元标识的 `removed_groups`。
这些字段不进入配音或对齐缓存键。已有配音的稿件在名称变化时也需显式“更新稿件名称”才采用，
避免恢复旧稿或编辑画面导致原音频失效。

导出增加 `shots.json`，记录镜头版本、采样点起止、展示类型、任务、来源讲解单元、过渡方式和短镜头检查。
它由 `timeline.json` 派生，不另行计时、不修改字幕。预览、暂停后跳转和导出均直接根据目标采样点恢复视觉状态；
动画跨段落时不重新开始。最终帧仍按全局帧时间生成，转场分支按同一整数采样点计算。

`services/roundup_sync.py` 是时间依据：24 kHz PCM16 单声道的整数采样点。
需要重采样时先用 FFmpeg 转为该格式，长度取源采样数按采样率换算后四舍五入，尾部按明确采样数补齐 / 截断。
该结果先送对齐，再按相同 PCM 规则拼接；不在对齐后去除静音。
段间停顿取 `round(pause_seconds * 24000)` 个采样点。段落位置累计整数，不逐段累计浮点误差。

对齐返回的全部文本须与最终 TTS 文本在去标点 / 空格后的顺序一致；不做模糊匹配或时长比例分摊。
时间须有序、无越界；空结果、异常零时长、丢字和跨词单元边界均拒绝，并提供人工校准。
自动结果仍需试听，程序校验不能证明模型边界在听感上准确。

画面、字幕、预览及导出读取同一份单元起止与全局位置。分组 / 总结同时高亮相关任务，
右侧显示任务事实摘要，不把朗读字幕放进详情卡。空隙和段间停顿保持上一状态，直到下一单元开始。
动画从切换点启动，在原有时段内完成，不延长总时长。拖动时直接计算目标时间的完整状态。

整期配音齐备时，预览播放同一条按采样点拼接的 WAV，画面时钟读取 `QMediaPlayer.position()`。
只具备当前段配音时可播放该段；缺音频的段落继续明确使用无声预览时间。
刷新定时器不累计有声播放时间，支持暂停、拖动、段落选择、任务定位和播放结束。
定位到单元或段落时，毫秒播放器位置向上取整，避免落到前一段；偏差小于一毫秒。

未对齐 / 失败的有声段只做段落级单任务或分组展示，不平均分配任务时间。
无音频时沿用已标明的预览轮播，不能作为真实同步结果。缺少模型不会删除音频。

## 导出与检查

保留 MOV、分段 WAV、稿件和清单，增加 `timeline.json` 和同步版本 / 状态。
音频齐备时导出整期 `narration.wav`，SRT 按有效讲解单元生成；无单元时间的段落使用段落级字幕。
`subtitle_precision` 分别记录 `unit`、`mixed`、`paragraph` 或 `preview`，没有逐字精度声明。
沿用 `paragraphs.srt` 文件名以兼容旧交付；具体精度以清单为准。
默认画面导出且整期音频齐备时，另外合成带音轨 MP4；字幕另存，没有烧进右侧卡片。

帧边界采用整数采样点的累计向上取整：`ceil(global_sample * 30 / 24000)`。
每一帧用对应的全局帧时刻计算局部时间，渲染耗时不参与时序。
最后一帧保持最后状态；音频长度保持实际采样数，视频尾部量化差不超过一帧。

测试 `tests/test_roundup_sync.py` 使用明确标识的 PCM / 对齐夹具验证机制及 FFmpeg 帧一致性，
不能替代真实 Qwen 合成、强制对齐和听看验收。当前真实检查及未完成事项见
`build/roundup-sync-20261102/REPORT.md`。
