# SpaceWeekly 安装与制作流程测试构建

- EXE 内嵌同版本 MSI，共用中文安装向导、离线用户协议草案与安装目录选择。
- 安装界面采用统一品牌页眉、简洁内容区与底部操作，支持浅色与深色；沿用已有安装目录。
- 发射部分一次制作并输出一个带配音的 MP4，默认保留 1.5 秒尾帧。
- 新闻按稿件勾选顺序分别输出带配音、透明通道的 MOV；矢量模板作为程序资源保留，MOV 本身是视频。
- 配音、对齐、渲染复用统一时间表和缓存，成功条目保留，失败后可重试。
- 增加本期发射字段编辑，保留原始来源；修复英文月份造成的口播数字校验误报。

这是本地 QA 构建，不自动发布线上更新。用户协议仍为待法律审核草案，Windows 发布者签名尚未配置。
配音质量、实际强制对齐误差与不同剪辑宿主兼容性需要分别验收，文件生成成功不等于读音正确。
