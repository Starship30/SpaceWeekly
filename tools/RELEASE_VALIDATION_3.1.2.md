# SpaceWeekly 3.1.2 新闻编辑修复

## 用户流程

- 资料页的新闻配图区域，以及新闻配音页，都可以勾选“使用本条配图”。取消后不用于预览和导出，
  已下载的文件保留；自动收集不会重新启用。可在资料页更换候选图或导入自行寻找的本地图片。
- 稿件列表默认选中已保留的全部新闻，支持全选、全不选、上移、下移及 Alt+方向键。
  取消的新闻仍可查看和编辑。选择、顺序和已有口播随期次保存；旧草稿缺少稿件选择记录时默认全选。
- 在“逐次卡片”点击“从当前稿件建立卡片”，只载入勾选新闻，按稿件顺序连续编号。
  时间排序仍可选择，切回“按稿件／载入顺序”恢复原顺序；保存后继续保留该模式。
- “生成新闻周报稿”进行筛选和摘要准备；“生成本条口播稿”生成当前新闻的口播提案。
  采用前会展示现有稿件和提案，采用后可以继续人工修改并预览最终 TTS 输入，不自动覆盖原稿。

## 原因和实现

新闻口播调用遗漏 `request_json` 必填的 `module_name`，请求还没有发给模型就失败。
此前测试替换整个请求函数，没有验证真实函数签名。现在补全参数，新增经过真实 JSON 封装的回归检查。

实际请求另发现合法原标题引用会被正文专用校验误拒。现在同条新闻的标题、正文都能作为逐字引用依据，
仍拒绝不存在的引用和来源未支持的数字，允许一次有拒绝原因的修正重试。
信息简短时要求简短表达，不把报道日期当成事件日期，也不向口播填充材料缺口说明。

选择和顺序复用现有新闻 bundle 与稳定新闻 ID；不建立另一套内容数据。
资料来源列表与稿件顺序使用独立列表容器并继续共享原 Article，避免排序后资料详情错认新闻。
图片使用状态保存在原图片清单，正式素材不删除。仅画面和排序变化不使已有配音失效。

- `build/news-editor-services-final.log`：58 项新闻图片、口播、真实 JSON 调用契约、素材编号、顺序、
  原有时间排序、旧范围兼容等检查通过。音频相关用例使用明确标记的测试 PCM，不是真实模型推理。
- `build/news-editor-desktop.log`：40 项桌面工作流检查通过；随后针对资料列表与稿件列表分离的修正，
  `build/news-editor-final-focused.log` 两项针对性检查通过。
- 最初图片迁移测试因测试自身创建的 SQLite 连接未关闭而发生 Windows 文件占用；修正该测试的
  连接关闭后，图片和其他相关检查全部通过，没有改动生产数据库行为。
- 使用当前工作区的真实哈勃新闻及现有 `deepseek-flash` 配置，实际请求成功。
  一次请求因引用原标题被旧校验拒绝，另一次不受支持数字被拒绝并修正；未放宽事实检查来冒充成功。
- 在独立副本中，通过真实按钮再次生成哈勃新闻口播，显示采用确认，采用后人工精简为：
  “美国航天局的哈勃空间望远镜研究了37个邻近矮星系，发现其中大量预期能观测到的氧缺失。”
  最终 TTS 输入的数量显示为“三十七个”。真实模型提案仍需审稿，不能保证每次表达都自然。
- 同一真实界面中取消 Swift 新闻、下移哈勃新闻，确认口播仍属于哈勃，编号变为陨石新闻 01、哈勃 02。
  关闭哈勃配图并拖动预览，确认图片不显示、新闻条和编号 02 保留。
- 从稿件载入并实际生成两条 PNG MOV：陨石新闻 01、哈勃新闻 02，各 12 秒、360 帧。
  ffprobe 确认没有音轨，清单顺序为 `selected_articles_input_order`。
  这是原有无声新闻素材条验收，没有冒充新配音或音画同步验收。
- 保存、正常关闭和重新打开独立副本后，新闻条顺序和所选两条恢复。
  原工作区稿件与素材没有被替换；最初失败的模型请求按原软件规则留下了一份诊断日志，
  后续验收诊断保存在项目目录，未记录 API 密钥。

## 安装产物和限制

交付目录为 `dist/SpaceWeekly-3.1.2-Final/`。旧 3.1.0、3.1.1 及本轮中间候选产物保留，未发布 GitHub Release。
最终冻结程序检查日志为 `build/news-editor-final-packaged-smoke.log`。
`build/news-editor-release-audit.json` 复核七项发布文件校验值，并从最终 EXE 读取编译函数，
确认包含配图、选择和排序相关的最新修正；独立 `Uninstall.exe` 继续保留。

本轮未重新加载 Qwen 模型、合成实际配音或进行人工试听，不宣称数字和专名读音已通过听辨。
未重跑完整安装升级矩阵或全部系统缩放组合。Windows 代码签名仍未配置，SHA256 仅作完整性校验。
