# 发射综述口播与读法

稿件页选中任务段，点击“口播整理”。先查看“修改前 / 整理后口播 / 最终 TTS 输入”，再点击“采用口播”。取消不改稿。此操作按已保存事件资料整理，省略额外背景；需要保留背景时可人工编辑或在“段落操作 → AI 润色口播”中处理。AI 润色同样先比较再采用。

正式任务资料、事实原稿、屏幕文字、口播、最终 TTS 输入分别保存。整理只更新独立口播和讲解单元，不改变快照、任务身份、原始出处或屏幕全名；前后版本保存在草稿的 `polish_history`。界面采用不等于任务背景已人工确认。

整稿生成、单段重写、选段润色共用 `roundup_style` 规则。用户自定义规则保留，并追加本轮关于去重、编号、日期衔接和工位的共同约束。本地模板使用同一事件口播服务，明确标记为本地模板，不冒充 AI 生成。

- 同组按时间讲述，组内相邻日期可用“当天”“第二天”加时段；切换国家或公司重新说日期。
- 已明确的单颗卫星不再重复单位和数量；多颗数量自然交代一次。整组成功只在组末说一次，结尾不再重复统计。
- 仅对有资料支持、已解析中文名称中的卫星编号范围做保守简化；如果本期其他所选任务包含相同系列名称，保留编号。未知专名和品牌不猜译。
- 工位取明确的主编号短名称，原始别名保留在正式资料及屏幕中。LC/SLC 等前缀的读法沿用可编辑发音规则，不擅自丢掉前缀。
- 有资料时自然交代目标轨道；同组轨道相同可在组末合并，不逐项重复。画面在载荷旁显示同一轨道名称，缺失显示“待补充”，口播不补造。目标轨道不代表实际入轨证明；近地轨道不能推成太阳同步轨道，也不从用途猜高度或倾角。采用新口播后须重新配音与对齐，原人工稿不自动覆盖。

`roundup_reading` 对明确的中文日期、带“星”的任务编号、编号范围及工位分别转换。前导零逐位读，范围读“至”；型号、版本号、小数及其他连字符不做全局替换。用户发音规则按最长原文一次匹配，优先于自动读法，不递归改写替换结果。读法预览与 TTS、对齐、导出的输入共用 `speech_text`。

整段按自然语义合成，不按逗号发出请求。讲解单元保留任务 ID 和原文位置，并记录转换后的文本及位置；跨单元的替换不能悄悄套用。AI 润色多任务段须返回明确关联的单元，缺失时保留原稿并提示，不能搜索任务名猜关联。

音频缓存以实际最终文本、模型、工作进程和运行设置为依据；无关发音规则不会导致全部重配。旧缓存仅在旧身份、当前文本和文件完整性均匹配时兼容读取。口播或相关读法改变后，旧音频及时间表不再作为当前结果，旧文件仍保留；人工校准继续显示待复查。

最终字幕和视频使用重新合成音频的统一时间表。`reading_map.json` 记录读法规则版本、各层文本、任务关联及实际同步精度。自动对齐结果仍需试听核对，程序通过不能证明读音正确。
