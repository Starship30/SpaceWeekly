# 在 SpaceWeekly 中生成视频素材

工具栏「视频素材」共用 Python 绘制与 FFmpeg 编码，生成新闻条、发射卡和极简片头。不需要加载 UXP 或 CEP；已停用的 CEP 实验仍保持停用。

窗口沿用主程序 ThemeManager：浅色/深色配色、圆角卡片、下拉框和主按钮一致。视频窗口分为素材列表、内容编辑、动画预览三列，可拖动分隔线调整宽度。

## 新闻条和发射卡

1. 从项目源码启动：`python app.py`。旧 EXE 尚未重新打包。
2. 在设置中启用「Premiere 内容包」，正常生成周报。发射范围启用时，同一 JSON 附带本次 LL2 采集的结构化发射信息，不重复采集。在「设置 → 发射任务」启用「启用航天术语翻译」并选择翻译模式；中文模式下，火箭、任务、轨道、载荷和地点自动使用现有词典/缓存/AI 翻译，与 Word 共用翻译器。词典模式仅翻译命中项；AI/混合模式的未知词需要可用的 AI 配置。翻译失败保留原文并写日志。
3. 点击「视频素材」并选择 JSON。在素材列表上方选择「时间正序（默认）」或「时间倒序」。先列新闻，再列发射；新闻按原始发布时间、发射按原始发射时间，在各类内分别排序。同一时刻保留原顺序，缺失或无效日期放到各类末尾；仅填写显示时间的手动发射也视为缺失原始日期。**只给勾选项连续编号，新闻与发射各自从 01 开始**；取消勾选后后续序号立即补齐，例如选第 1、3、5 条显示 01、02、03。未勾选行不显示序号，仍可编辑文字；勾选后才显示动画预览。切换排序保留文字编辑、勾选和当前条目。列表、预览、MOV 和清单一致。
4. 新闻条为一行标题和一行摘要，长摘要缓慢滚动。发射卡使用斜侧面板，可编辑火箭、任务、目标轨道、任务载荷、地点和时间。显示时间按设置中的时区转换，不加 UTC+8 等后缀；原始日期与时区元数据保留。旧 JSON 的 UTC/GMT 后缀也会在预览和 MOV 中隐藏。缺失字段显示「待确认」；载荷默认仅为 LL2 任务名称，不推断卫星数量或质量。也可点击「新增发射任务」手动填写。
5. 设置最短时长、编码与输出目录，点击「生成所选素材」。默认 12 秒；发射卡至少 12 秒，新闻长摘要按滚动距离延长。生成在后台执行，可以取消。
6. 点击「打开输出目录」，只导入 `manifest.json` 中 `selected: true` 且 `current: true` 的最新文件，按照清单顺序放到 Premiere 背景视频上方的视频轨道。未勾选项的序号为 `null`、`current: false`，此前文件保留但不属于当前输出选择。

透明素材统一为 1920×1080、30 fps。默认 **PNG MOV 无损（小体积）**，每帧独立编码，保留 RGBA。仍可选择原有 **ProRes 4444**。同一张 36 秒新闻条实测 PNG 为 55,253,075 字节，ProRes 为 264,211,704 字节，减少约 79%；实际体积随文字、时长、画面复杂度改变。新 PNG MOV 尚需在 PR 26.3 试播；如果不能导入或实时播放不顺，选 ProRes 重新生成。

## 自定义片头与保存模板

1. 在「视频素材」点击「制作片头」。不需要先加载 JSON。
2. 编辑名称、副标题，以及**开始日期和结束日期**。默认包含今天在内的最近 7 天；例如 `2026-10-04` 到 `2026-10-10`，画面显示 `2026.10.04 - 2026.10.10`。日期范围可任意修改，结束日期不能早于开始日期。
3. 选择本地组徽素材：静态 PNG/JPG/WebP，或动态 GIF、MP4/MOV/M4V。保留宽高比；PNG、GIF 或支持 Alpha 的 MOV 保留原透明区域，普通 MP4 的原背景会保留，不自动抠图。留空使用自绘示例标志。界面显示静态预览，动态素材仅显示首帧。
4. 静态组徽可选「淡入」「平滑缩放」「上浮淡入」，默认淡入。缩放采用固定画布与浮点居中，避免尺寸取整时的位置跳动。动态组徽保留自身动画，静态动效选项禁用；**短视频播放一次后停在最后一帧**，保持到片头统一淡出。GIF 仍循环播放；长素材最多取前 7 秒，不使用源音频。
5. 点击「保存模板」，保存一份本地模板到 `output/video-intro/intro-template.json`（跟随视频输出目录）。下次打开恢复名称、副标题、组徽路径和静态动效，**不会固定旧日期**。每次打开重新默认最近 7 天；旧模板未保存动效时使用淡入。组徽文件应保持在原路径，保存模板不复制素材。
6. 点击「生成片头 MP4」，完成后点击「打开片头视频」查看实际动画。输出为 7 秒、1920×1080、60 fps 的 H.264 MP4，深色不透明背景，细线展开、文字依次平滑滑入并淡出。可直接放到 PR 片头位置。当前无音频，也无透明背景。

示例：`output/video-intro-logo-trial/` 包含三种静态动效和 GIF、透明 MOV、普通 MP4 的实际生成结果，各片头约 117–620 KB，以及预览 GIF。`sample-logo.*` 为自绘示例素材，可替换为自己的标志。短视频保持末帧的新版示例与记录位于 `output/video-intro-hold-trial/`；此前循环版本保留，不覆盖已生成文件。

## 文件、复用与取消

- 编辑只修改窗口里的副本，不覆盖原始 JSON。生成前保存 `edited-snapshot.json`；也可「另存编辑快照」。
- 原快照的 ID、日期和顺序不变；编辑副本及生成清单记录所选排序，序号只用于画面显示。默认素材位于 `output/video-cards/<job_id 哈希>/`；清单记录 ID、类型、编码、顺序、时长及指纹。
- 英文旧 JSON 和手动输入不会在离线导入/渲染时调用 AI。需要自动翻译时，启用现有航天翻译设置并重新生成内容包；原快照不会被悄悄改写。
- 重复生成复用有效文件；修改内容、时长、编码、代码或字体后才重生成。切换排序或勾选范围后，序号变化的卡片重生成，序号未变的有效卡片可复用；另一类的编号不受影响。**旧 MOV 保留**，避免破坏 PR 已引用的素材。更换编码不会自动减小此前文件；确认工程已换用新素材后，再自行清理不再引用的旧版本。
- 失败或取消清理当前临时文件，保留此前完成项。关闭正在生成的窗口会取消并等待工作线程退出。不承诺整批原子回滚；强制结束进程或断电不保证清理。

## 环境与验证

需要项目 requirements 中的 Pillow、PATH 中的 FFmpeg/ffprobe，以及本机已有的微软雅黑粗体和 Bank Gothic 字体。缺少依赖会报出具体错误。没有下载或分发字体，也没有恢复 CEP。

验证命令与详细文件协议见 [脚本说明](VIDEO_CARDS.md)。87 项相关检查通过，包括勾选项连续编号、时间排序、翻译复用/缓存/回退与取消，以及组徽居中、动效、GIF 帧时长/透明/清除方式/循环、视频解码失败与取消、首帧缓存和模板兼容；AI 请求测试使用模拟响应。此前实际运行 Qt 窗口 → QThread → FFmpeg，检查发射 PNG MOV、中文日期区间片头、保存模板和原 JSON 保留。本轮实际 FFmpeg 生成六个 60 fps 片头，检查 GIF/透明 MOV/MP4 的解码和循环，并离屏复查浅色/深色界面、动态素材首帧预览与动效保存；记录见 `output/video-intro-logo-trial/verification.json`。这些均不代表 Premiere 宿主验收。用户已确认此前 ProRes 新闻条、发射 MOV 可在 PR 使用；新 PNG MOV 与新片头尚未在真实 PR 中验证，EXE 尚未重建。

## 视频搜索、下载与扫码登录

在已有「视频素材」窗口上方点击「视频下载」。不必先导入 JSON；导入后任务下拉框读取发射任务名称（summary），默认排除新闻；「包含新闻条」仅影响下载窗口，原素材列表不变。可填写多个 UP 主 UID/空间链接，或从结果添加 UP 主；结果和任务默认按时间正序排列，可切换倒序/相关度。支持 Bilibili 搜索、BV/av/b23 单链接解析、MP4 画质选择、后台下载、进度/速度/取消，以及打开文件或目录。需要更多可用画质时可点击「哔哩哔哩扫码登录」，用手机 App 扫码确认；会话使用 Windows 当前用户加密保存在 Workspace，关闭窗口或重启后保留，退出登录删除；平台会话过期仍需重新扫码。登录后重新解析视频，不保证额外画质或下载权限。

选择 JSON 任务后默认按其原始发射时间匹配北京时间当天及次日发布的视频，例如 10.09 对应 10.09–10.10。勾选使用权限后，「全部发射任务下载 Demo」按默认时间正序遍历 JSON 全部发射任务（始终排除新闻），每项按自身日期检索、最多解析前三条候选，下载一条最高可下载画质 MP4（同分辨率优先 H.264）。显示整批进度和逐项结果，单项失败继续、取消停止整批；无日期或无匹配不会下载其他日期的视频。本批视频集中在 Workspace/video-downloads/运行日期/，同日多批加序号，文件按原视频标题命名，同名加序号；已完成文件保留。关闭时间匹配可手动不限日期搜索。

下载独立存放在当前 Workspace 的 `video-downloads/`，每份素材带 `metadata.json`，不修改新闻条、发射卡、片头、原始 JSON 或生成清单。重复请求相同链接及格式时复用经过验证的完整文件；其他格式及缺失文件使用新的目录，避免覆盖 Premiere 已引用的素材。

此功能的可选依赖、Windows EXE 配置、三个参考项目的源码分析、真实下载验证及未验证项见 [视频下载说明](VIDEO_DOWNLOAD.md)。当前 GitHub 的旧 EXE 不包含此入口，需要重新打包。
