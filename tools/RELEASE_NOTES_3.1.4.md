# SpaceWeekly 3.1.4

- 加快配音页切换新闻时的响应。口播先更新，画面预览、自动恢复写盘和本地发射资料同步在后台处理。
- 整理制作页面和设置。新闻列表支持按当前筛选范围跨页三态全选，翻页、改稿和后台任务完成后尽量保留原浏览位置。
- 新闻按事件归并，保留相关来源。支持手动合稿、预览、撤销，以及缺料汇总和失败项重试。已保存的人工稿和配音保留。
- 「本期设置」支持保存周报名称，默认使用「航天周报」。完整视频导出支持背景配乐、固定音量、淡入淡出和播放列表。
- 完善发射资料详情、任务画面分页和字幕校准。统一片头、新闻与发射综述的期次设置。
- Windows 安装器提供中文安装向导。已有工作区和独立部署的语音环境可继续使用。

Windows x64 安装包提供 SHA-256 校验。安装包尚未配置 Windows 发布者签名。语音环境与模型在软件内单独配置。
