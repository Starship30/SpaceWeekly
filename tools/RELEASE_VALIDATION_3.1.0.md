# 3.1.0 本地发布验收

本次未发布 GitHub Release、未创建或覆盖标签。主程序版本为 3.1.0，验收版本使用独立
`Starship30.SpaceWeekly.QA` 标识，避免覆盖用户正在使用的正式程序和工作区。

## 交付

- 最终文件目录：`dist/SpaceWeekly-3.1.0-Final`，以其中 build-info.json、SHA256SUMS.txt 为准。
- EXE 一键安装器、MSI 安装器、完整更新包、公开更新源元数据和便携包均已实际构建。
- 安装目录根部有独立 `Uninstall.exe`，更新/安装快速回调补齐它；设置 → 关于调用同一入口。
- 原生 EXE 安装器的已安装提示仍由 Velopack 提供（修复、打开目录、取消）；
  如需安装文件本身的“修复 / 卸载”维护页，使用官方 MSI 版本。
- 新闻、发射资料、稿件和词典不写入发布包；FFmpeg/ffprobe、字体、语音部署脚本随包。
- 安装、导入、存储、发布步骤见 [INSTALLER_UPDATES.md](INSTALLER_UPDATES.md)。

## 已完成的真实检查

1. 通过 Setup.exe 安装测试 A，开始菜单快捷方式启动，选取含中文和空格的隔离工作区。
   旧资料通过实际导入服务先备份再复制，原目录保留。
2. 通过软件入口检查、下载损坏包，SDK 实际返回 SHA256 不匹配，原版本继续可用。
3. 真实测试发现 SDK 的已安装基础包和本地待安装记录省略校验字段。
   已改为原始发布清单校验实际文件；缺少基础校验时使用完整包。未将空字段当成校验成功。
4. 原生 Velopack SDK 完成 qa.1 → qa.2；随后用 MSI 安装/修复 qa.3，返回码均为 0，
   通过创建的开始菜单快捷方式启动。由于首次卸载后的延迟目录移除与紧接着的安装发生重叠，
   又执行了 MSI 强制修复并成功启动；复测脚本后续应等待卸载目录移除完成再重装。
5. 在软件“关于”页完成 qa.3 → qa.4 的检查、下载、重启更新，实际主程序版本变为 qa.4。
   特意修改期次名称，重启更新先出现未保存提醒，选择保存后新名称保留。
6. 配置、正式图片及清单、DPAPI 测试凭据通过检查；模型路径仍指向独立 D 盘。
   测试凭据是合成 canary，不是真实账号登录验收。
7. 新闻下拉菜单实际截图确认使用圆角弹出层，三个真实新闻条目仍可选择。
   发射模式一/模式二同时保留；模式二沿用原版条，使用已采集任务生成 12 秒 ProRes 4444 MOV，
   ffprobe 确认零音轨。MP4 仅用于方便预览，透明素材以 MOV 为准。
8. 最终冻结程序检查移除外部工具 PATH、屏蔽系统字体并放置无效同名 FFmpeg，
   实际验证包内工具、字体、MOV/MP4、Word、TLS 和时区。
9. 软件内真实更新到 qa.5 后，安装目录根部生成独立 `Uninstall.exe`（281600 字节）。
   主程序运行时执行静默卸载返回 10，主程序继续运行，没有强制结束。
   正常退出后，该文件调用 MSI 卸载并移除程序，用户数据检查通过。
10. 使用最终代码的 qa.6 分别执行全新 MSI 和 EXE 安装，两者均由安装回调生成根部
    `Uninstall.exe`；再分别通过该文件真实卸载，均返回 0 且主程序文件移除。
    配置、正式图片/清单、测试凭据校验保持一致，独立语音目录仍存在。
    DPAPI 合成凭据在升级与卸载后实际解密成功。

## 测试与界面证据

- `build/installer-validation/desktop-release.log`：桌面工作流回归。
- `build/installer-validation/uninstall-voice-verified.log`：独立卸载入口、目录保护及语音部署边界。
- `build/installer-validation/release-tests.log`：启动、缓存与打包检查。
- `rounded-news-dropdown.png`、`update-unsaved-protection.png`、`corrupt-update-rejected.png` 为实际界面截图。
- `mode2-silent/verification.json` 记录真实任务 ID、来源、MOV 流信息和零音轨结果。
- `fresh-uninstall-results.log` 记录 MSI/EXE 安装与独立入口卸载的真实结果，
  `standalone-msi-uninstall.log` 记录升级后独立卸载；测试软件已移除。

这些验证在当前 Windows 开发机完成，Codex 的 MSIX 宿主存在 AppData 目录虚拟化；
不是干净虚拟机或另一台用户电脑验收。部分组合 Qt 测试曾在音频回放用例停滞，已保留日志，
隔离执行桌面套件通过；独立 .NET 卸载探针需正常 Windows 权限，在受限执行令牌下曾无法运行。
