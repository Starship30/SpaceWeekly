# 每周发射综述口播规则（2026-10-31）

整稿生成、单段重写和选段润色共用现有 **AI 写作规则 → 每周发射综述**。
规则进入 `AppSettings.roundup_prompt` 及原有模板的 `roundup` 字段；旧配置缺少这些字段时采用新默认规则。
综述编辑页的 **写作规则** 使用同一个编辑器，没有新增独立设置页。保存规则不改已有草稿。

## 实际修改

- 按国家或国家加公司组织，同组按时间排序。航天科技集团称“中国方面”，中国民营公司保留公司，
  SpaceX/Rocket Lab 使用美国归属；发射地独立处理，未知机构不从发射地点推断国别。
- 七天过去范围使用固定开头；其他范围明确日期。结尾由程序统计决定是否添加“本期关注的 N 次发射均取得成功”，
  部分收录和部分选择不声称全球全部。发射与回收分别判断。
- 取消旧的强制 LL2 口头归因，禁止例行归因和空泛过渡；来源与确认状态仍完整保存。
  可省略整个次要背景断言；保留预测、争议、用途等断言时仍须保留相应限定。
- 同一份结构化事件包含显示时区换算、日期/时段、发射场、工位、完整火箭、结果及有明确证据的数量。
  背景与事件均关联任务 ID 和出处，模型复核还检查跨日指代及合并任务的事实。
- 屏幕须保留完整火箭与已知工位编号；已知载荷数量必须在口播明确说出，不能只藏在英文任务名中。
  正式名称、朗读、发音替换后的 TTS 输入继续分别保存，对应表仍可供下一轮对齐使用。
- LL2 机构国家字段兼容字典及数组；发射场和工位分开提取。未改原始机构、原始 LL2 响应及任务身份。
  旧快照不自动升级，缺少的信息不会根据型号猜测；时区不同需显式新建范围快照。
