# 单条新闻配音

## 使用

选择“新闻周报”，在“稿件”页选择一条新闻，打开“口播与最终朗读”。
可以手动填写口播稿，也可以使用现有文本模型“生成口播稿”，查看提案后决定是否采用。
标题和摘要仍用于原有新闻条卡，不会自动成为朗读正文。

“最终 TTS 输入”显示术语、日期、数量和可编辑发音规则处理后的文字。
点击“配音与预览”，确认本条后生成；环境未配置时进入现有配置入口。
复用同一套 Qwen 工作进程、环境、音色、取消和按需卸载功能，不安装第二套语音服务。
配音后卸载 TTS，再运行已配置的 ForcedAligner；对齐失败仍保留 WAV，并标明段落级字幕、待校准。

“试听本条”复用有效缓存；“停止播放”停止试听；后台任务可通过底部“取消运行任务”取消。
“同步与画面”内可以重新生成本条或打开已有同步校准表，编辑时间、试听附近及恢复自动结果。
播放、暂停和拖动使用播放器实际位置，字幕与预览读取同一份整数采样点时间表。
同一新闻换句不会重新播放整张条卡的入场动画。

在“导出”页打开原有新闻导出按钮的菜单，选择“导出选中新闻配音与视频”。
原有 Markdown、Word 和 Premiere 新闻稿导出入口继续保留。
新素材包包含 `spoken.txt`、`reading.txt`、`source.json`、原始 `voice.wav`、统一时钟的
`narration.wav`、`subtitles.srt`、`timeline.json`、可恢复的 `draft.json` 和 `manifest.json`。
视频沿用现有新闻透明信息条：MOV 保留透明通道；带音轨 MP4 将透明区域合成黑底，适合验收和叠加素材。
不自动添加未经提供的新闻背景画面，字幕保持独立 SRT。

## 保存、缓存和失败

稳定身份沿用 Premiere 的 URL SHA256 新闻 ID；新闻音频、对齐及播放缓存与发射综述分别存放。
工作区的 `cache/news_audio`、`cache/news_alignment`、`cache/news_playback` 和
`output/news-drafts` 保存结果；期次保存与恢复同时保存口播、读法、关联单元和历史音频信息。
导出目录使用时间与随机后缀，不覆盖旧版本。

修改标题或屏幕摘要不会让音频失效；修改口播、读法、说话人、模型或有效推理设置会标记旧音频过期。
生成新音频后，旧对齐和人工校准不能套用。已有成功音频和历史版本在失败、取消时保留。
人工稿件不会被文本模型直接覆盖。新闻单元关联新闻 ID，不要求填写火箭、工位或发射任务 ID。

## 验证范围

`tests/test_news_voice.py` 的 PCM 和对齐失败测试是明确标记的测试夹具，不是模型验收。
桌面回归另覆盖后台结果按新闻 ID 归档、切换新闻、保存恢复和原有发射综述。
真实模型验收资料位于 `build/news-voice-20261103`，与用户原工作区分开。
详见其中的 `验收记录.md`，区分真实模型运行、程序检查及仍需人工试听的项目。
